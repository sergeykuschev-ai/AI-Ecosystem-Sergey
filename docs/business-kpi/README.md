# Business KPI Web v1

Модуль KPI для бизнес-части Артура.

Цель первой версии — перенести проверенную KPI-логику из Excel в веб-приложение внутри существующего репозитория и Docker-инфраструктуры, не меняя рабочие контракты Purchasing.

## Источник истины v1

На первом этапе источником данных служат проверенные Excel-файлы KPI 2026. После сверки веб-расчётов с Excel источник истины планируется перевести на данные 1С.

## Функции v1

- Dashboard;
- смены;
- месячная статистика;
- годовая статистика;
- продавцы;
- премии;
- настройки KPI;
- импорт Excel;
- экспорт Excel;
- аудит изменений;
- роли доступа.

## Ключевые правила расчёта

- если эквайринг уже включает QR, выручка = наличные + эквайринг;
- QR не прибавляется к выручке второй раз;
- средний чек = выручка / чеки;
- товаров в чеке = продано единиц / чеки;
- планы, цели и комиссии хранятся централизованно в настройках;
- пустые месяцы не должны искажать средние и годовые показатели.
