# Локальный запуск AI-закупщика на macOS

Файл `scripts/start-purchasing-web-macos.command` запускает локальный
веб-интерфейс AI-закупщика без ручного ввода npm-команд в Terminal.

Интерфейс доступен только на этом компьютере:

```text
http://127.0.0.1:3210
```

## Подготовка

Node.js и npm должны быть установлены и доступны в `PATH`.

Один раз откройте Terminal в корне репозитория и сделайте launcher
исполняемым:

```bash
chmod +x scripts/start-purchasing-web-macos.command
```

После этого файл можно запускать двойным кликом в Finder.

## Ярлык на рабочем столе

Рекомендуемый вариант — Finder alias:

1. Откройте каталог `scripts` в Finder.
2. Выберите `start-purchasing-web-macos.command`.
3. В меню **File** выберите **Make Alias**.
4. Перетащите созданный alias на рабочий стол.
5. При желании переименуйте его, например в `AI-закупщик`.

Вместо Finder alias можно создать символическую ссылку из Terminal:

```bash
ln -s "$(pwd)/scripts/start-purchasing-web-macos.command" \
  "$HOME/Desktop/AI-закупщик.command"
```

Простая копия одного `.command`-файла на рабочий стол работать не будет:
launcher специально определяет корень репозитория относительно каталога
`scripts`. Если требуется именно копирование, копируйте репозиторий целиком
и запускайте файл из каталога `scripts` внутри его копии.

## Запуск

Дважды нажмите на launcher или его alias.

Launcher:

- проверит наличие `node` и `npm`;
- найдёт корень репозитория относительно собственного расположения;
- проверит порт `3210`;
- повторно использует уже работающий AI-закупщик;
- при необходимости запустит `npm run purchasing:web`;
- дождётся готовности сервера;
- откроет `http://127.0.0.1:3210` в браузере.

Окно Terminal остаётся открытым, пока работает запущенный им сервер.
Повторный двойной запуск откроет интерфейс, но не создаст второй сервер.

## Остановка сервера

Перейдите в окно Terminal, из которого был запущен AI-закупщик, и нажмите:

```text
Control+C
```

После остановки адрес `http://127.0.0.1:3210` перестанет отвечать.

## Если macOS блокирует запуск

Если macOS сообщает, что файл нельзя открыть:

1. Нажмите на launcher правой кнопкой мыши.
2. Выберите **Open / Открыть**.
3. Подтвердите запуск.

Либо откройте **System Settings → Privacy & Security** и нажмите
**Open Anyway / Всё равно открыть** для заблокированного launcher.

Если Terminal сообщает `Permission denied`, повторите:

```bash
chmod +x scripts/start-purchasing-web-macos.command
```

Если launcher сообщает, что `node` или `npm` не найдены, проверьте их в
Terminal:

```bash
node --version
npm --version
```

После установки или настройки Node.js полностью закройте Terminal и
запустите launcher ещё раз.
