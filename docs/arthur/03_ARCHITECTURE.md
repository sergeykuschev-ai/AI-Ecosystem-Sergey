# Arthur OS — Architecture

## Поток запроса

```text
Telegram / Web / Voice
        ↓
Arthur Gateway
        ↓
Intent Router / Orchestrator
        ↓
Memory + Tasks + Permissions
        ↓
System Service or Skill
        ↓
Validation + Confirmation
        ↓
Response + Audit Log
```

## Базовые компоненты

- **Telegram** — первый пользовательский интерфейс.
- **n8n** — расписания, события, проверки и интеграции.
- **PostgreSQL** — структурированная память, задачи, решения, статусы и аудит.
- **LLM provider** — понимание запросов, планирование и формирование ответа.
- **Google Calendar** — календарные события и свободные окна.
- **Gmail** — почта и контроль ожиданий.
- **Docker** — изоляция и развёртывание.
- **GitHub** — код, документация и история изменений.

## Журналирование

Для каждого действия фиксируются:

- инициатор;
- время;
- намерение;
- использованный модуль;
- входные данные и источник;
- выполненное действие;
- необходимость подтверждения;
- результат и ошибка;
- ссылка на связанную задачу или решение.

## Надёжность

- резервное копирование PostgreSQL;
- секреты только в переменных окружения или секрет-хранилище;
- тестовый и рабочий режимы;
- идемпотентность автоматизаций;
- запрет автоматических необратимых действий;
- возможность отключить каждый навык отдельно.
