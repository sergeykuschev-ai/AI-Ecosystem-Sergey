# Arthur OS — Ideas

Этот файл хранит идеи, которые не должны автоматически становиться задачами разработки.

## Критерии переноса в backlog

Идея переносится в backlog только если:

1. она относится к существующему модулю или обоснованно создаёт новый;
2. не дублирует память, задачи, календарь или другой сервис;
3. имеет понятного пользователя и сценарий;
4. даёт измеримый результат;
5. не мешает текущему приоритету.

## Очередь идей

- голосовой интерфейс Артура;
- собственное мобильное приложение;
- автоматические звонки для записи на услуги;
- коммерческая версия Arthur OS для других владельцев бизнеса;
- расширенная аналитика личного Instagram;
- единый клиентский профиль и CRM сети;
- локальные модели для безопасных внутренних задач.

Идеи из этого списка не реализуются до отдельного решения.
