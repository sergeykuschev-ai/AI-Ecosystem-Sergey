# Arthur OS — Development Rules

## Рабочий цикл

1. Выбрать один измеримый результат.
2. Проверить место функции в архитектуре.
3. Подготовить точное техническое задание.
4. Ограничить изменяемые файлы.
5. Реализовать одну задачу.
6. Запустить релевантные тесты.
7. Проверить реальный пользовательский сценарий.
8. Обновить документацию и changelog.
9. Сделать отдельный коммит.

## Ограничения

- не начинать следующий модуль до завершения текущего;
- не устанавливать новые инструменты без прямой пользы;
- не передавать Codex весь репозиторий без необходимости;
- не смешивать рефакторинг с новой функцией;
- не менять production storage без отдельного решения;
- не считать задачу завершённой без проверки результата.

## Definition of Done

Функция готова, когда:

- ей можно пользоваться;
- обработаны основные ошибки;
- есть тест или воспроизводимая проверка;
- действия журналируются;
- права доступа соблюдены;
- документация соответствует коду;
- понятен следующий операционный шаг.
