# Arthur — предупреждения о повторных технических сбоях

**Сервер выполнения:** Windows Amursk, Docker `arthur-core-telegram-gateway-1`.
VPS — только транзит и исходники; не переносить на него память, ключи или KPI.

## Как работает

- Windows Scheduled Task `Arthur-Dev-Worker-Health` раз в час сохраняет read-only
  технический снимок пяти зарегистрированных проектов.
- Gateway в существующем Telegram long-polling цикле раз в 5 минут проверяет
  **два самых свежих** снимка. Отдельного Telegram polling процесса нет.
- Предупреждение только после двух **различных по времени** отчётов,
  разделённых минимум 30 минутами (максимум 2 часами), где один и тот же
  проект дважды отмечен `degraded`.
- Последний отчёт должен быть не старше двух часов; первый — не старше трёх.
  Пропущенные, устаревшие, `not_checked`, повреждённые отчёты не вызывают
  предупреждение.
- Названия проектов из allowlist, только авторизованный личный Telegram ID.
  Текст не содержит токенов, содержимого ответов сервисов, клиентских данных,
  SQL, путей или ошибок сетевого стека.
- Для каждого инцидента заранее атомарно создаётся marker `incident-<id>.json`
  в приватном постоянном каталоге. Повторный запуск Gateway **не дублирует**
  сообщение. Два следующих отчёта `healthy` сбрасывают marker и позволяют
  сообщить о новом отдельном сбое.
- Если Telegram не подтвердил отправку после claim, результат считается
  `delivery_unknown`. Слепого повторного отправления **нет**, чтобы не
  создать дубликат; проверить журнал события
  `project_health_alert_delivery_unknown`. Это ограничение отказоустойчивости
  первой версии, не гарантированная доставка.
- Система проверяет доступность, **не корректность** выручки, эквайринга,
  операций 1С, оплаченных заказов или поисковой индексации.

## Хранение в Амурске

- Reports (read-only mount):
  `C:\AI-Ecosystem\local-services\arthur-dev-worker-reports` →
  `/var/lib/arthur-project-health`.
- Persistent alert markers (private read-write mount):
  `C:\AI-Ecosystem\local-services\arthur-project-alert-state` →
  `/var/lib/arthur-project-alert-state`.
- Переменная `ARTHUR_PROJECT_ALERT_STATE_DIR=/var/lib/arthur-project-alert-state`.
  Если нет директории или ровно одного доверенного Telegram пользователя,
  автосигнализация не активируется.
- Образ: `arthur-core-telegram-gateway:project-alerts-v1-20261009`,
  зафиксирован в локальном `docker/arthur/compose.override.yml`.
- Для восстановления: `C:\AI-Ecosystem\candidates\arthur-project-alerts-20261009\compose.before-alerts-v1.yml`
  и предыдущий Docker образ `project-health-v2-20261009`.
