# Arthur OS — Memory Model

## Виды памяти

### Профиль
Стабильные данные о пользователе, магазинах, предпочтениях и правилах работы.

### Проектная память
Контекст, решения, статусы и артефакты по закупщику, сайту, Instagram, Академии и другим проектам.

### Операционная память
Активные задачи, сроки, ожидания, события календаря и следующие действия.

### Журнал решений
Фиксирует не только решение, но и его причину, альтернативы, дату, автора и условия пересмотра.

### Временный контекст
Данные текущего диалога, которые не обязаны попадать в постоянную память.

### Архив
Завершённые проекты и устаревшие сведения, доступные для истории, но не используемые как текущая истина.

## Правила записи

- постоянная память хранит только полезные и проверенные сведения;
- чувствительные данные разделяются по доменам;
- пароли, данные карт и одноразовые коды не сохраняются;
- противоречия не затираются молча — создаётся запись об изменении;
- каждое важное решение имеет источник и дату;
- пользователь может запросить просмотр, исправление или удаление памяти.
