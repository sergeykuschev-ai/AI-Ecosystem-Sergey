# Arthur OS — видение проекта

**Статус:** канонический документ проекта  
**Версия:** 1.0  
**Дата:** 2026-07-29

## Миссия

Создать единую AI-систему «Артур», которая помогает Сергею Кущеву управлять личными делами, бизнесом, знаниями и автоматизациями через один интерфейс.

Артур — не отдельная языковая модель и не набор разрозненных агентов. Это слой управления над памятью, задачами, сервисами и специализированными навыками.

## Целевой пользовательский опыт

Пользователь обращается к одному Артуру обычным языком:

- «Что у меня сегодня?»
- «Проверь почту и ожидаемые ответы».
- «Что снять для Instagram?»
- «Проанализируй смену Миски».
- «Проверь заказ Валты».
- «Кто из сотрудников плохо знает ассортимент?»

Артур сам выбирает нужный модуль, использует разрешённые данные, объясняет результат и запрашивает подтверждение перед необратимыми действиями.

## Долгосрочное состояние

Артур должен стать единой операционной системой жизни и бизнеса:

- помнить важные факты и причины решений;
- вести задачи, календарь и ожидания;
- контролировать почту и напоминания;
- помогать с поездками и записями;
- поддерживать личный Instagram;
- подключать закупщика, KPI, ревизии и обучение сотрудников;
- использовать общую базу знаний;
- помогать принимать решения, оставляя окончательный выбор за владельцем.

## Что Артур не делает

Артур не должен:

- создавать параллельные памяти, календари и списки задач;
- принимать финансовые или юридически значимые решения без подтверждения;
- отправлять важные письма без разрешения;
- скрывать выполненные действия;
- передавать личные данные бизнес-модулям без необходимости;
- переписывать работающие модули только ради новой архитектуры;
- раздувать проект функциями, которыми нельзя пользоваться.

## Критерий успеха

Каждый новый этап должен уменьшать ручную работу и давать функцию, которой можно пользоваться сразу после завершения цикла разработки.
