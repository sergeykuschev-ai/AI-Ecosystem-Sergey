# Амурск Маркет — защищённая доставка заявки на аудиорекламу

Состояние на 09.10.2026: **кандидат, не развёрнут**.

## Причина изменений

Сайт amurskmarket.ru/reklama принимает заявки. Имеющийся на VPS сервис
`arthur-advertising-relay` проверял HMAC подпись сайта, но затем отправлял
текст в общий маршрут Arthur `/notify`. При этом в рабочем Gateway уже
есть отдельный подписанный маршрут
`/internal/amurskmarket/advertising-lead`, который до последнего времени
был отключён из-за отсутствующих настроек загрузки signing secret.

## Что делает кандидат

- проверяет HMAC SHA-256 входящего запроса прежним ключом;
- передаёт в Arthur **исходное JSON тело без повторной сериализации**
  и исходную подпись `x-amurskmarket-signature`;
- адрес назначения берётся из доверенного `ARTHUR_NOTIFY_URL`, при этом
  маршрут переопределяется на подписанный advertising-lead endpoint;
- не отправляет в общий `/notify` неподписанное сообщение;
- не выводит содержимое заявок и секреты в stdout.

## Состояние и условия выпуска

- Модуль-кандидат прошёл `node --check`;
- действующий рекламный relay на VPS по-прежнему **healthy**, не менялся;
- из relay достижим текущий Arthur Gateway (`/health`: HTTP 200);
- в PR #245 исправлены функции чтения настройки inbound channel, но
  производство ещё не переключено;
- старые HMAC файлы остались в своих хранилищах; перенос на Windows был
  заблокирован средствами безопасности, обходить запрет нельзя.

**До релиза обязательны:** разрешённая подготовка файла действующего
HMAC секрета на Windows Amursk, read-only mount и enabled конфигурация
соответствующего Gateway; проверка отказа unsigned/invalid signature,
затем контрольный signed TEST event с гарантиями отсутствия
повторного уведомления; canary с быстрым rollback. Отдельно проверить
защиту общего `/notify` от неавторизованных источников, не нарушая
существующие служебные уведомления.

Это уведомления о **новых заявках рекламодателей**. Для звуковых
плееров четырёх магазинов остаются отдельные задачи — heartbeat,
подтверждённые фактические выходы роликов и аварийные уведомления
о сбоях устройств. Их нельзя назвать внедрёнными по одному здоровому
сервису заявок.
