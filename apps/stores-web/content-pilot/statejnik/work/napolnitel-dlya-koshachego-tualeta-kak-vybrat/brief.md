# Brief

Читатель: владелец кошки, который выбирает тип наполнителя и хочет понимать бытовые различия без рекламного рейтинга.
Основной вопрос: чем отличаются комкующиеся и впитывающие наполнители, а также древесные, минеральные и растительные варианты.
Короткий ответ: выбирать нужно по поведению кошки, типу уборки, пыли/разносу, весу и правилам утилизации конкретного продукта.
Ожидаемый результат: читатель выбирает 1-2 подходящих типа для теста небольшой упаковкой.
Границы: без медицинской диагностики, без рейтинга брендов, без обещаний "полностью устраняет запах".
Добавочная ценность: сценарная таблица выбора и правила безопасного перехода.
Канонический запрос: как выбрать наполнитель для кошачьего туалета.
