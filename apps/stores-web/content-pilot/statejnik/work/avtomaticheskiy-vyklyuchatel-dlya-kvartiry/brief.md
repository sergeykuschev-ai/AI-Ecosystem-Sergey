# Brief

Читатель: человек без специальной электротехнической подготовки, который хочет купить автоматический выключатель для квартиры или дома.
Основной вопрос: какие параметры нужно знать до покупки и почему нельзя выбирать автомат только по мощности приборов.
Короткий ответ: автомат подбирают как элемент защиты линии; важны параметры проводки, номинальный ток, характеристика срабатывания, число полюсов и отключающая способность.
Ожидаемый результат: читатель собирает исходные данные и понимает, когда нужен электрик.
Границы: без проектирования щита, без расчёта конкретной квартиры, без инструкции по самостоятельной замене под напряжением.
Добавочная ценность: практический список "что записать перед походом в магазин".
Канонический запрос: как выбрать автоматический выключатель для квартиры.
