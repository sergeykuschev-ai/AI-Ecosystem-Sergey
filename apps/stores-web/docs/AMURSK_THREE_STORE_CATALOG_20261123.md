# Каталог Ампер / Вентиль / Метиз Маркет — кандидат

Дата: 23 ноября 2026 года. Статус: кандидат в отдельной Git-ветке. Не опубликован.

## Подтверждённое состояние

- На production amurskmarket.ru проверены информационные страницы трёх магазинов, но публичных товарных карточек для них нет.
- На stores-web1 настроен обмен CommerceML для отдельного каталога «Миски»; этот поток запрещено использовать как источник трёх строительных магазинов.
- Подтверждённой номенклатурной выгрузки 1С отдельно по «Ампер», «Вентиль», «Метиз Маркет» пока нет.
- Существующая ветка f71a33e содержит экспериментальный мульти-магазинный receiver, но конфликтует с актуальной основной веткой и не опубликована.

## Реализованный кандидат

- Роуты /catalog/amper/, /catalog/ventil/, /catalog/metiz-market/ и изолированные страницы товаров /catalog/{store}/{productId}/.
- Поиск по названию, артикулу, штрихкоду; фильтры категорий; пагинация.
- Для каждой витрины только отдельный файл {store}.json из абсолютного пути AMURSK_CATALOG_DATA_DIR, не из Git или «Миски».
- Проверка схемы, источника 1С, соответствия магазину, уникальности ID, времени экспорта и проверок цены/остатка.
- Устаревшая цена (более 72 часов) или остаток (более 24 часов) не отображаются.
- Пока нет подтверждённого набора, витрина пустая, без цен и вымышленных товаров, noindex.
- Выдача для поисковика index допускается лишь при наличии товаров и проверке снимка менее 48 часов назад.
- Товары с непроверенной ценой не индексируются как отдельные карточки.

## Входной JSON, без фиктивного ассортимента

Снимок: schemaVersion 1; source "1c-verified"; store (один из amper, ventil, metiz-market); exportedAt, verifiedAt (ISO 8601 UTC или с явным смещением); published true; products — массив товаров только этого магазина.

Товар: id (строгий URL-safe идентификатор), name, category, опционально sku, barcode, unit, description, priceRub, priceVerifiedAt, stockQuantity, stockVerifiedAt.

Ключ source и published не должен выставляться до подтверждения реальной выгрузки 1С и соответствия организации, вида цены и склада. Валидация: node --import tsx scripts/store-catalog/check-snapshots.ts /absolute/path. Скрипт только проверяет, ничего не публикует.

## Блокировки дальнейшего этапа

1. Получить отдельно по каждому магазину структуру каталога и данные от 1С: ID, название, иерархия, артикул, цена, валюта, склад, остаток, дата обновления и статус продажи.

4. Изолированная QA-проверка мобильной версии и поиска, затем отдельное разрешение на production-релиз.
