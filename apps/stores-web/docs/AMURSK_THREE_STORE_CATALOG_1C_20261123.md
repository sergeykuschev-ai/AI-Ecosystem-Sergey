## Проверенные факты по действующей 1С

Проверено только на DESKTOP-6NKDIC8 посредством GET к локальному интерфейсу 1С OData с существующим DPAPI-доступом.

- Метаданные OData: HTTP 200, 1169 EntitySet.
- Catalog_Номенклатура: HTTP 200. Содержит Ref_Key, Description, Артикул, Parent_Key, IsFolder, DeletionMark, описание и другие поля.
- Catalog_Склады: HTTP 401, в том числе при ограничении по трём известным складам и allowedOnly=true.
- Catalog_ВидыЦен: HTTP 401; Catalog_Организации: HTTP 401.
- InformationRegister_ЦеныНоменклатуры25_RecordType: HTTP 200; в метаданных есть Номенклатура_Key, ВидЦены_Key, Цена, Period.
- AccumulationRegister_ТоварыНаСкладах_RecordType: HTTP 200; в метаданных есть Склад_Key, Номенклатура_Key, ВНаличии, КОтгрузке, RecordType и Period. Строки движений НЕ являются проверенным текущим свободным остатком.

## Добавлен изолированный импортёр (без подключения production)

- lib/store-catalog/import-contract.ts: проверяет независимую карту соответствий магазина и исходную полную выгрузку 1С; отклоняет чужой магазин, Миску, чужой склад, организацию/тип цены, папки, удалённые позиции, дубли, старые/отрицательные или неподтверждённые цену и остаток.
- scripts/store-catalog/prepare-import.ts: по умолчанию выполняет только проверку без записи.
- Вход 1: уже сверенная полная выгрузка для конкретного магазина. Требуются source=1c-ut-verified-store-export, completeness=all-active-sellable-items, stockMethod=1c-free-to-sell-current-balance, priceMethod=1c-effective-retail-price-with-vat, registerState=reconciled, валюта RUB и достоверные записи каждого товара.
- Вход 2: отдельно проверенная карта соответствий со статусом verified-by-owner, организацией, складом, розничным видом цены, датой и независимым доказательством проверки. Заполнение карты вымышленными сведениями запрещено.
- Чистая проверка: node --import tsx scripts/store-catalog/prepare-import.ts --input /secure/export/amper.json --mapping /secure/approved/amper.json
- Для подготовки уникального кандидата: дополнительно --write-staging --out /secure/catalog-staging. Файл имеет имя вида amper-TIMESTAMP-NONCE.candidate.json, права 0600. Скрипт никогда не создаёт amper.json в активной директории.
- Успешная проверка формата не заменяет проверку достоверности реальной 1С. Данные ещё НЕ получены, товаров для публикации нет.
