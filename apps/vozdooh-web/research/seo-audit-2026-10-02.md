# VOZDOOH — technical SEO audit, 2 октября 2026

Issue: #202. Проверка выполнена на активной ветке VOZDOOH и реальном staged-каталоге 1С.

## Что исправлено

- Индексация теперь управляется одним fail-closed флагом `SEARCH_INDEXING_ENABLED=true`. Без явного `true` сайт остаётся `noindex/nofollow` и `robots.txt` запрещает обход.
- При включённом флаге глобальный HTTP `X-Robots-Tag: noindex, nofollow` убирается, а публичные страницы получают `index, follow`.
- `robots.txt` при включении разрешает публичный сайт и блокирует `/api/`, `/cart`, `/checkout`.
- Sitemap очищен от страниц, которые сами остаются `noindex`; в нём только реально индексируемые discovery/content routes.
- Публичные страницы получили управляемые robots directives, canonical URL и базовые OpenGraph title/description; карточка товара также получает подтверждённое локальное изображение для OG, когда оно есть.
- Для товара уже используется `Product` + `BreadcrumbList` JSON-LD с фактическими SKU/brand/GTIN/ценой/остатком только при наличии этих данных.
- Для страниц брендов и категорий добавлены `CollectionPage` + `ItemList` + `BreadcrumbList`; у брендовой страницы `Brand` берётся только из точного названия landing page. Рейтинги, отзывы и неподтверждённые claims не создаются.
- Исправлен конфликт robots на 404: несуществующая карточка возвращает HTTP 404 и только `noindex`, без второго `index, follow`.

## Проверка включённого режима индексации

Тестовый production build запущен с `SEARCH_INDEXING_ENABLED=true`.

- `/`, `/catalog`, товар, бренд, категория, `/collections`, `/finder`: HTTP 200, `robots=index, follow`, корректные canonical URL; проверенные типы имеют OpenGraph title.
- Товар CULTI: canonical на собственную карточку, Product/Breadcrumb JSON-LD, OG image из подтверждённого локального изображения.
- Бренд CULTI и категория Diffusers: CollectionPage/ItemList/Breadcrumb JSON-LD; у бренда присутствует Brand entity.
- Несуществующий товар: HTTP **404**, robots только **noindex**.
- `/privacy`, `/offer`, `/user-agreement`, `/payment`, `/delivery`, `/returns`, `/contacts`, `/cart`, `/checkout`: остаются **noindex/nofollow**.
- `robots.txt`: `Allow: /`; disallow `/api/`, `/cart`, `/checkout`; sitemap указывает на `https://vozdooh27.ru/sitemap.xml`.

## Что намеренно НЕ включено в индекс

Страницы оплаты, доставки, возврата, контактов и юридические документы сохраняют текущий `noindex` и не включены в sitemap. Они не должны попадать в индекс автоматически только из-за общего launch switch; их можно переводить в index отдельно после финального подтверждения содержания и операционного состояния.

## Осталось при публичном запуске

1. В production environment установить `SEARCH_INDEXING_ENABLED=true` **до production build/redeploy**.
2. После выкладки проверить production `robots.txt`, `X-Robots-Tag`, canonical и sitemap теми же smoke checks.
3. Добавить/обновить sitemap в кабинетах поисковых систем и запросить переобход ключевых URL.
