# VOZDOOH — контракт выгрузки клиентов из 1С

Цель: после подключения 1С забрать старую клиентскую базу VOZDOOH без смешивания персональных данных с публичным сайтом или Git.

## Канонический JSON

```json
{
  "customers": [
    {
      "customerId": "внутренний идентификатор 1С",
      "name": "Имя клиента",
      "phone": "+7 924 000-00-00",
      "lastPurchaseAt": "2026-01-15T10:30:00+10:00",
      "totalSpendRub": 42000,
      "ordersCount": 8,
      "marketingConsent": true,
      "consentSource": "карточка клиента / анкета / документ",
      "consentAt": "2024-03-10T00:00:00+10:00"
    }
  ]
}
```

Обязателен только телефон. Остальные поля передаются, только если реально существуют в 1С.

## Правила

- Телефон нормализуется в +7XXXXXXXXXX.
- Дубли по телефону объединяются.
- Персональные данные пишутся только в приватный файл на сервере с правами 0600.
- Импорт не пишет телефоны или имена в консольные логи.
- `marketingConsent` никогда не выводится из факта покупки или наличия телефона.
- Для рекламной реактивации автоматически допустимы только записи с явным `marketingConsent: true`.
- `false` означает явный отказ.
- отсутствие значения означает неизвестный статус и не считается согласием.

## Запуск после получения выгрузки

```bash
npm run customers:import -- /secure/path/vozdooh-customers.json
```

По умолчанию приватный результат:
`/opt/vozdooh/data/crm/customers-private.json`.

Импортёр выводит только агрегаты: количество строк, уникальных клиентов, дублей, некорректных телефонов и статусы согласия.
