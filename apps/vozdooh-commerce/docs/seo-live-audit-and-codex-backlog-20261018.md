### Факты

- 194 URL в sitemap, 194 уникальных, все ответили HTTP 200.
- 145 URL раздела /catalog, включая сам /catalog; 144 товарных страницы имеют Product JSON-LD.
- 14 URL /brands, 11 /categories, 11 /collections, 7 /guides; всего 194.
- Для всех 194 страниц: один корректный canonical, присутствуют meta description и H1, нет noindex в sitemap.
- 144/144 товарных страниц имеют Product schema.org; структурированные данные коллекций включают CollectionPage/ItemList/BreadcrumbList.
- robots.txt (HTTP 200) ссылается на sitemap; служебные корзина и checkout имеют noindex. Платёж, оферта, приватность, возврат и соглашение тоже имеют noindex и не входят в sitemap — не считать это дефектом без отдельного решения.
- Дублирующихся title среди sitemap-страниц — **одна пара**: /catalog/teatro-dolce-vaniglia-500 и /catalog/teatro-dolce-vaniglia-refill-500. У них разные URL, цена и товарные SKU, но одинаковый <title>.
- Короткие (<60 символов) описания **7** тематических коллекций: warm-interior (45), fresh-air (46), woods-and-spices (47), floral (50), living-room (46), bedroom (45), focused (54). Это редакционная возможность, **не самостоятельная ошибка индексации**. Google не устанавливает универсального порога длины метаописания.
- Дополнительно проверены внутренние ссылки с 8 значимых страниц: главной, каталога, списка коллекций, home-fragrance, gift-diffusers, статьи о диффузорах, страниц брендов и категорий. Вне sitemap встречались ожидаемые /cart и страницы юридической информации с noindex; обнаружение этих ссылок не является сигналом битых маршрутов.
- Анализ **не устанавливает**, индексируют ли страницы Яндекс/Google, есть ли показы, CTR, клики, фильтры или санкции. Это измеряется в Яндекс Вебмастере и Google Search Console, а не выводится из sitemap.

## Приоритеты следующей разработки

### SEO-01 · P2 · Уникальный товарный title для рефилла TEATRO Dolce Vaniglia

**Подтверждение:** <title> обеих карточек буквально одинаков, при этом обычный формат /catalog/teatro-dolce-vaniglia-500 стоит 12 000 ₽, а рефилл /catalog/teatro-dolce-vaniglia-refill-500 — 8 500 ₽ по данным аудита. Не подменять реальные цены в коде SEO и не обещать фиксированное наличие.

**Задание Codex:** В изолированной ветке Codex от закреплённой ревизии 0401235 изучить `apps/vozdooh-web/app/catalog/[slug]/page.tsx` и реальные редакционные идентификаторы товаров `655467` и `DV500RTFU`. Сделать название *рефилла* отличимым в SEO title (например «Рефилл DOLCE VANIGLIA 500 мл — TEATRO…»), не меняя имя обычного диффузора и данные из 1С. Не хардкодить цену. При возможности использовать общий чистый helper и тестировать обе карточки. Сохранить уникальные canonical и валидную Product/Offer JSON-LD.

**Приёмка:** тест с двумя указанными SKU/slug; title не равен между ними и точно обозначает формат refill; реальные другие SEO-заголовки не испорчены; unit + TypeScript + ESLint + isolated build PASS; git diff только source/tests/docs; без деплоя.

### SEO-02 · P2 · Конкретные описания семи тематических коллекций

**Подтверждение:** descriptions вышеперечисленных 7 коллекций сейчас 45–54 символа и почти не помогают выбору товара. Источник: `src/catalog/collections.ts` → `app/collections/[slug]/page.tsx`.

**Задание Codex:** Улучшить семь editorial descriptions в `apps/vozdooh-web/src/catalog/collections.ts`. Для «тёплых», «свежих», «древесных/пряных», «цветочных», «для гостиной», «для спальни», «для концентрации» написать по одному уникальному осмысленному русскому описанию ориентировочно 90–160 символов. Учитывать реальные фильтры коллекций, проверенные правила family/room/mood; объяснять, для каких предпочтений полезна подборка, не обещая лечебный эффект, наличие каждой позиции, скидки или ускорение доставки. Не трогать действующую форму оплаты.

**Приёмка:** уникальные description и OpenGraph на семи маршрутах, корректный H1 и canonical, существующая структурированная разметка не нарушена; проверка не зависит от выдуманных товарных свойств; unit + TypeScript + ESLint + isolated build PASS; без публикации.

### SEO-03 · P2 · Автоматический read-only аудит после изменения сайта

**Задание Codex:** Разработать отдельную тестовую проверку (не в production Cron) доступности sitemap, 200/canonical/noindex/title/Product schema для всех публичных страниц с ограниченной конкуренцией и временем выполнения, без сохранения клиентских данных и без POST. Выводить дифф и красные флаги, отличая P0/P1 инциденты от P2 редакционных улучшений. Не ставить каждые сутки одну и ту же задачу на основании неизменного метаописания.

**Приёмка:** локальные синтетические fixtures; обнаружение 404/дубликата/отсутствия canonical; успешный прогон на известном публичном snapshot, без ложных претензий о поисковой индексации; автономный запуск в Arthur только после отдельной проверки ресурсоёмкости.

### SEO-04 · P1 аналитика, зависимость от доступа · Индексация в Яндексе/Google

Для реального органического роста нужны данные за последние 28–90 дней из Яндекс Вебмастера и Google Search Console: сколько URL известно, проиндексировано/исключено, причины исключений, показы, клики, CTR и запросы по РФ. Не публиковать, не менять права владельца и не выдумывать числа. Это задача получения данных и анализа, не программный патч. При отсутствии подключённого доступа нужна явная авторизация владельца.

## Последовательность

1. Взять SEO-01 и SEO-02 по очереди через безопасный Arthur → Codex; не создавать две активные задачи одновременно.
2. После каждого изменения проверить отдельный worktree и предъявить owner review; затем перенести конкретный проверенный коммит в develop/vozdooh (cherry-pick после проверки на конфликты и тестов), только после согласования.
3. Отдельно согласовать публикацию production. Нельзя автоматически сливать в main, отправлять git push, менять 1С, цены, платёжные сценарии и заказные данные.
4. После подключения данных Вебмастера ранжировать следующие задачи по видимости и конверсионному потенциалу, а не по длине description.
