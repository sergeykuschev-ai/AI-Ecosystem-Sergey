## Реализация

`/collections/vozdooh-selection`, название «Подборка VOZDOOH» (название в
задании отображалось вопросительными знаками). Отдельное правило
`researchSelection` использует существующий `demandRank` для порядка 25 SKU.
После `withValidImages` применяется `isPubliclyPurchasable`: активность,
положительная цена, остаток по существующему публичному контракту, slug,
проверенное локальное изображение и исключения витрины. Недоступные позиции
исчезают, число позиций берётся из результата. Пустая подборка отсутствует
в доступных коллекциях; её страница возвращает существующий notFound.

Ссылка добавлена в существующий блок навигации по брендам на главной и
отображается только при непустой подборке. Используются текущие шаблон,
карточки, стили и семантические ссылки. Новых изображений, CSS и анимации нет.
Гид различает домашние форматы, автомобильное саше и рефил; доставка ограничена
доступными пунктами Ozon и оплачивается отдельно, самовывоз в Хабаровске бесплатный.

Существующее правило `demand` и состав `popular` сохранены: только 14 SKU
с `merchandisingSignal`, без расширения до исследованных 25. Значение
`verified` не переопределяется как двухисточниковое bestseller-доказательство.
Цены, остатки, 1С, API, checkout, платежи, worker и существующая политика
индексации не менялись. Искусственный lastmod не добавлялся.
