## Изменения

- Для `/catalog/teatro-dolce-vaniglia-500` и `/catalog/teatro-dolce-vaniglia-refill-500` добавлено различение HTML/Open Graph title: префикс «Аромадиффузор» для торговой категории `Диффузоры`, «Рефил» для `Рефилы`. Slug ограничивает область исправления двумя проверенными страницами; тип определяется исключительно `trade.category`. При неизвестной категории сохраняется прежний title. Остальные товары сохраняют прежние заголовки.
- Отдельный `landingMetadataDescription` используется только в description и Open Graph description страниц брендов и категорий. Имеющиеся title сохранены. Длинный `landingSearchDescription`, редакционный текст и отображение страницы не изменены.
- Краткое описание сохраняет имя посадочной страницы, называет только форматы с положительным остатком и добавляет «В наличии» только при наличии таких товаров. Форматы добавляются целиком по доступному месту. Сохраняются доставка в доступные пункты Ozon по России и самовывоз в Хабаровске. Цены, бесплатная доставка и всеобщая доступность Ozon не обещаются.
- Цель длины — 140–165 символов, предел — 170. Слова не обрезаются: выбираются целые названия форматов и предложения. Для гипотетического будущего слишком длинного имени возвращается явная ошибка, требующая редакционной проверки; все текущие имена проходят проверку с синтетическим ассортиментом.

Canonical, H1, Product/Offer JSON-LD, наименования, цены, остатки, sitemap и правила индексации не изменены. `lastmod` не добавлялся. Корзина, платежи, 1С, доставка как интеграция и конфигурация сайта не затронуты.
